# 2026-11-22: 30-task A/B eval

**Setup:** 30 tasks (11 TS, 8 Python, 5 Go, 4 Rust, 1 C, 1 Zig), defined in `evals/tasks.json`. Each task was built twice by Sonnet from identical scratch repos (`evals/setup.sh`): **A** without the skill, **B** told to follow `SKILL.md`. Neither knew it was being evaluated. A blind Opus judge saw the two builds as X and Y (the mapping alternates by task), ran both test suites, probed for bugs, and scored 7 dimensions from 1 to 5. Script: `evals/workflow.js`.

**All 8 of A's wins were on correctness.** B's code was much cleaner but missed edge cases. The judges' probes found bugs nobody had tested for.

### Signature failures (judge-extracted bad examples, 89 total)
- **Without the skill:** unrequested features (11), boolean soup (11), stored derived state (9), branch ladders (8), duplication (6), defensive noise (6).
- **With the skill:** **spec-bending (9)**, where a requirement was dropped or weakened to keep the design small; missing transition tests (3); scattered transitions (2).

The skill's own failure mode is over-correction: simplicity pressure leaked from *how to build* into *what to build* and *how much to test*.

## Fixes applied to SKILL.md
- **"The spec is the floor."** Simplicity cuts how you build, never what was asked for. If the clean design can't meet a requirement, change the design.
- **Every empty table cell is a decision.** Rejections must still give back what they owe (a returned coin, a collected error).
- **Slow exits get their own state** (`cancelling`). **Notify listeners last** and re-check state afterwards. **Re-entering the current state is a no-op.**
- **Tests: small test code, many cases.** At least one row per requirement, plus edge cases. Never write a test that locks in a bug.
- Checklist items for spec coverage, empty cells, and notification order.

## Caveats
- One judge per task and one sample per side, so treat single-task results as noisy and the aggregates as the signal.
- `examples/llm-failures.md` was linked from SKILL.md mid-run, so some round-1 B agents may have seen it.
- The judge rubric is aligned with the skill's principles by design. The correctness score and the probes are the independent check.
